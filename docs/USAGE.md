# 守岸人 DeepSeek 桌宠使用说明

完整介绍与安装步骤见 [项目说明](../README.md)。本版连接官方 DeepSeek Harness Windows 客户端。

## 首次连接

登录 Harness，从系统托盘完全退出。启动桌宠，右键 → 设置 → 连接 DeepSeek → 安装 / 更新 Harness 连接插件，再打开 Harness。

## 常用设置

| 想做什么 | 在哪里操作 |
| --- | --- |
| 查看所有会话状态 | 点桌宠右上角的状态圆钮；或右键 → 会话状态列表 |
| 跟随任务状态 | 右键 → 自动跟随当前任务；或 设置 → 连接 DeepSeek → 跟随的会话 → 自动跟随最近活动 |
| 给动作选择 GIF | 交互工作室 → 左侧动作 → GIF 素材 |
| 添加自己的素材 | GIF 素材 → 打开素材目录 / 导入图片，之后刷新 |
| 设置循环、速度、下一状态 | 交互工作室 → 播放与切换 |
| 多条语音随机播放、每条单独配字幕 | 交互工作室 → 语音与配对气泡 |
| 只显示音频对应的字幕 | 气泡与字体 → 气泡内容 → 自定义音频+字幕 |
| 调整待机语音频率 | 待机动作 → 自动播报频率 |
| 只在每轮任务开始说一次 | 思考动作 → 同一轮任务只播一次 |
| 缩放桌宠 | 右键 → 设置 → 字体与大小；或 Ctrl + 滚轮 |
| 改气泡和余额条大小 | 拖动各自左右边缘；或大小设置中的预览控制 |
| 查看金额 | 桌宠底部余额条；悬停看明细；右键刷新余额 |
| 随 Harness 自动启动 | 设置 → 连接 DeepSeek |
| 保存、导入或导出便携包 | 设置 → 保存与迁移 |

支持 GIF、动画 WebP、PNG、JPG/JPEG；语音支持 WAV、MP3、OGG、FLAC、M4A、AAC；字体支持 TTF、OTF、TTC。

## 会话状态列表

桌宠右上角有一个圆形状态按钮，中间的数字是 Harness 当前已知的会话数量，圆环颜色跟随正在关注的会话状态；有会话进行中时，圆钮右上角多一个小圆点。

点一下圆钮会弹出会话列表，**按最近活动时间倒序**排列，每行显示：

- 状态色点与状态名（思考中 / 查阅中 / 编辑中 / 执行中 / 等你回应 / 已完成 / 出错了 / 已暂停 / 空闲）
- 会话标题
- 相对时间（刚刚 / N 分钟前 / N 小时前 / 昨天 HH:MM / MM-DD HH:MM）

点任意一行的三个操作互相独立：

| 操作 | 效果 |
| --- | --- |
| **单击**一行 | 只改桌宠关注的会话，列表保持打开，不抢你当前窗口的焦点 |
| **双击**一行 | 关注该会话，并把 DeepSeek Harness 窗口切到前台（未启动就启动它） |
| **右键**一行 | 菜单：关注这个会话 / 打开并跳转到 DeepSeek Harness / 复制会话标题 |

点「自动跟随」回到自动模式；再点一次圆钮、点击别处或窗口失焦即可收起。托盘和右键菜单里也有「打开 DeepSeek Harness」。

列表包含 Harness 客户端已知的**全部会话**，不只是桌宠启动后活动过的那些；子代理会话、空草稿和**已归档的会话**不会出现，也不算进圆钮上的数量。状态只从本地连接插件读取会话标识、标题与生命周期，不包含对话内容、工作区路径或凭证。

圆钮上的数字和列表都跟着 Harness 实时变化：新建、归档或删除会话后 1 秒内就会同步（桌宠每秒读取一次插件写出的状态）。

换电脑时导出 Windows 便携完整包。新电脑安装、登录官方 Harness 后，再安装一次连接插件。可以导入 Codex 版配置素材继续使用；账户和聊天记录不随桌宠包携带。

## 检查更新与升级

每次启动桌宠后自动检查 GitHub 正式版，有新版时提示。也可右键 → **设置 → 版本与更新 → 立即检查更新**；在 **设置 → 版本与更新** 中关闭启动检查、手动检查或恢复已忽略版本的提醒。检查失败不会打断使用。

新版提示提供打开更新页、备份配置与素材、稍后提醒和忽略该版本。更新需要手动下载安装：

1. 在 **保存与迁移** 中导出配置与素材 ZIP，保留一份备份。
2. 若发布页提供适用于当前版本的程序补丁，退出桌宠后将补丁解压到原目录覆盖，再重新启动。个人配置、GIF、音频、字幕和字体保留。
3. 若使用完整包，解压到新目录，再导入自己的配置与素材 ZIP。程序补丁直接解压覆盖，不在配置导入窗口中打开。

当前版本和下载链接见 [项目首页](../README.md)。Windows 音量合成器中可通过 **守岸人 · DeepSeek** 单独调整桌宠音量；托盘图标单击可唤醒或隐藏桌宠。

## 统一设置、静音与锁定

右键桌宠或托盘 → **设置…**。字体与大小、交互工作室、桌面与声音、保存与迁移、连接和版本更新都位于同一个窗口。

右键勾选 **安静陪伴（静音）** 后，立即停止当前及待播声音，自动播报和主动试听都不再发声。取消勾选后恢复原来的音量；静音期间的声音不会补播。也可在 **设置 → 桌面与声音** 调整。

鼠标移到桌宠身上，点击顶部居中的小锁，或勾选 **锁定桌宠** 后，不会因拖动、单击、双击、悬停、Ctrl + 滚轮或拖动气泡／配额条边缘而改变桌宠。任务动画、完成提醒和额度刷新仍会运行。点击顶部小锁即可解锁，也可通过托盘打开设置取消锁定。锁定时角色区域允许点击穿透，余额框可点击刷新；设置中的大小选项仍可调整。

两个开关自动保存，随配置素材包和完整便携包迁移。旧版“安静陪伴”开启时迁移为静音；旧版未提供的锁定功能默认为关闭。

### 锁定、穿透与余额刷新

鼠标移到角色上方，点击小锁即可锁定／解锁。锁定时点击角色可操作下方窗口；移入鼠标时角色淡化。淡化程度在「设置 → 桌面与声音 → 锁定悬停透明度」调整。小锁与余额框保留操作；点击余额框刷新，未锁定时拖动其左右边缘调整大小。通过托盘的设置入口也可解除锁定。

使用「关闭守岸人」退出程序。右键菜单不再列出锁定开关或返回 AI 客户端的按钮。

## 图标与快捷方式

设置 → 桌面与声音 → 底部栏与托盘图标：选择纯净图标或 APP 小标，立即应用并保存。Codex 为黑白 GPT 小标，DeepSeek 为蓝鲸小标。

首次正常启动 Windows 版会创建桌面快捷方式。删除后可在设置 → 保存与迁移 → 创建桌面快捷方式中恢复。将完整包迁移到新电脑后，启动一次即可创建当地的快捷方式。

## 客户端退出与更新来源

设置 → 连接 DeepSeek：可分别开启随客户端启动、随客户端完全退出而关闭。关闭窗口后还在托盘运行时继续陪伴；完全退出约 8–10 秒后关闭。先打开桌宠时等待客户端运行一次。

设置 → 版本与更新 → 更新来源：自动选择、GitHub 官方源、镜像加速（中国大陆网络）。自动模式连接 GitHub 失败时切换 GH-Proxy 镜像；固定来源后只走所选来源。更新窗口提供完整包、程序补丁和校验文件下载。下载补丁前仍需核对适用的旧版本。

## 点击余额刷新

鼠标移入余额框时显示手形。点击后，框内显示“刷新中…”，完成后恢复最新额度或余额；不另弹窗口，不触发语音或改变气泡。刷新失败时短暂显示“刷新失败”，之后保留上次读数。重复点击不会重复排队；左右边缘仍用于调整大小，锁定时只保留点击刷新。

## 显示或隐藏余额框

在「设置 → 字体与大小」的“余额框大小”旁勾选“显示余额框”。右键桌宠或余额框，也可使用刷新下一项的“隐藏余额框 / 显示余额框”。隐藏后去掉底部占位和鼠标区域；窗口贴边及适合屏幕只计算角色范围。再次显示恢复已设定的比例；任务动画、语音和气泡继续工作。设置自动保存并随配置素材包、完整便携包迁移。
